# mcp-where-to-watch

MCP-сервер: где смотреть фильмы и сериалы в российских стримингах — с живой проверкой
первоисточников (Кинопоиск, Амедиатека), а не только агрегаторных данных.

> **Disclaimer:** неофициальный инструмент, не аффилирован с JustWatch, Кинопоиском
> (Яндекс), Амедиатекой, Okko и другими сервисами. Данные принадлежат соответствующим
> сервисам, API неофициальные и могут измениться в любой момент. Инструмент предназначен
> для личного пользования, запросы минимальны (кэш каталогов 6 часов).

Данные агрегатора — неофициальный GraphQL API [JustWatch](https://www.justwatch.com), регион RU.

## Инструменты

- **`where_to_watch(query, kind="movie|tv|any", limit=5)`** — найти фильм/сериал по названию
  (рус. или англ.) и показать, где он доступен: подписка / аренда / покупка / бесплатно, с ценами и ссылками.
  Результаты сортируются: сначала доступные по подписке, внутри — по IMDb.
- **`check_kinopoisk(query, limit=3)`** — живая проверка на kinopoisk.ru (парсер первоисточника,
  данные точные в отличие от JustWatch): поиск по названию → статус онлайн-кинотеатра.
- **`check_amediateka(query, limit=3)`** — живая проверка Амедиатеки: каталог из их sitemap
  (1747 тайтлов, кэш 6 ч) → транслит-матчинг по словам слага → открытие страницы тайтла.
- **`popular_on(service, kind="movie|tv|any", limit=10)`** — популярное сейчас на сервисе.
  Сервисы: кинопоиск, окко, more.tv, премьер, амедиатека, ivi, mubi, apple tv, itunes, tvigle.

## Быстрый старт

Нужен только [uv](https://docs.astral.sh/uv/) — Python и зависимости он поставит сам
(из PEP 723-метаданных внутри `server.py`).

```bash
git clone https://github.com/WarLikeLaux/mcp-where-to-watch.git
cd mcp-where-to-watch

# проверка, что сервер стартует
uv run server.py
```

**Claude Code** (глобально, user scope):

```bash
claude mcp add --scope user where-to-watch -- uv run --directory /путь/к/mcp-where-to-watch server.py
```

**Claude Desktop** (`claude_desktop_config.json`):

```json
{
  "mcpServers": {
    "where-to-watch": {
      "command": "uv",
      "args": ["run", "--directory", "/путь/к/mcp-where-to-watch", "server.py"]
    }
  }
}
```

## Особенности API JustWatch (выяснено опытным путём, 2026-09)

- Кинопоиск имеет short_name **`kpk`**, а не `kpsk`. `ivi` в RU-провайдерах JustWatch
  **отсутствует** (сервис, видимо, больше не отслеживается), хотя ID `ivi` в выдаче
  всё же может мелькать.
- `searchTitles` требует аргумент **`source`** (работает `"ALL"`); у `popularTitles` его нет.
- `retailPrice` требует аргумент **`language`** и тогда возвращает **готовую локализованную
  строку** («99,00₽»), а не число.
- `objectType` есть на уровне **`node`**, а не `node.content` (в `MovieOrShowContent` его нет).
- GraphQL-ошибки валидации приходят с **HTTP 422** — тело ответа нужно читать всегда,
  `raise_for_status()` до парсинга JSON прячет реальные причины.
- Фильтр `TitleFilter.packages` у `popularTitles` для части провайдеров (kpk, ivi) молча
  игнорируется — поэтому «популярное на сервисе» фильтруется на клиенте.
- Справочник провайдеров: `GET https://apis.justwatch.com/content/providers/locale/ru_RU`
  (старый v1 REST, живой).

## Качество данных по провайдерам (проверено вручную 2026-09-24)

JustWatch по Кинопоиску (kpk) неточен **в обе стороны** (сверяли с реальными страницами
kinopoisk.ru через WebFetch — рендерятся без капчи, наличие кнопки «Смотреть фильм» отражают честно):

| Фильм | JustWatch | Реальность |
|---|---|---|
| Бэтмен: Начало (2005) | FLATRATE kpk | ❌ «Буду смотреть», смотреть нельзя — ложное срабатывание |
| Реквием по мечте (2000) | kpk нет | ❌ действительно нет — верно |
| Трасса 60 (2001) | kpk нет | ✅ «Смотреть фильм» есть — пропуск |

Отсюда в `where_to_watch`/`popular_on` пометки ⚠️ для kpk и fallback-ссылка на поиск
Кинопоиска, когда JustWatch говорит «по подписке нигде нет». Okko/more.tv/Premier противоречий
не дали, но Okko — JS-SPA, анонимно не перепроверить. Поиск на kinopoisk.ru работает только
по английским названиям (сам сайт подсказывает).

## Парсер Кинопоиска (`check_kinopoisk`)

Технические детали, чтобы не переоткрывать:

- **SSO-танец**: первый GET на kinopoisk.ru отдаёт 302 на `sso.passport.yandex.ru`, но
  выставляет куку `disable_server_sso_redirect=1` (Max-Age=3600). Повторный запрос с куками
  возвращает обычную SSR-страницу (~220 КБ). Никаких капч для анонима не видно (2026-09).
- **Поиск**: работает старый URL `index.php?kp_query=<запрос>` (кириллица ОК). ID кандидатов —
  `data-id="N" data-type="film"`, приоритет у блока `element most_wanted` («Скорее всего, вы ищете»).
  Новый URL `/search/?text=` отдаёт 301 и клиентский рендер.
- **Статус фильма** — по кнопкам онлайн-кинотеатра в разметке: `>Смотреть фильм<` /
  `>Смотреть по подписке<` → подписка; `Смотреть за N…₽` → аренда/покупка; иначе «Буду смотреть» →
  недоступен. ВАЖНО: матчить только с HTML-контекстом `>…<` — на каждой странице лежит
  JSON-конфиг UI с `"buttonText":"Смотреть сериал"`, который даёт ложное срабатывание
  при поиске по голой подстроке.
- Название для сверки — `<meta property="og:title">`: формат `«Трасса 60» (Interstate 60, 2001)`.
- Проверено на ground truth: Трасса 60 ✅ (есть), Реквием по мечте ❌, Бэтмен: Начало ❌ —
  всё совпало с реальными страницами.
- more.tv переехал на **wink.ru** (deep links из JustWatch ведут на хаб), Okko — чистый SPA
  без SSR — парсить их сложнее, пока не делали.

## Парсер Амедиатеки (`check_amediateka`)

- Каталог целиком лежит в `sitemap-content.xml` (фильмы) + `sitemap-seasons.xml` (сериалы):
  URL вида `/watch/movies_<id>_<slug>`, `/watch/series_<id>_<slug>`. Кэш в памяти на 6 часов.
- Поиска на сайте для анонима нет (SSR пустой, `_next/data` роуты 404, API
  `api.amediateka.tech/gateway/v1` строит методы на клиенте) — поэтому поиск = транслит
  запроса + матчинг **по словам слага** (иначе «мэри» влезает в «american», а «la» — в
  «лалаленд»). Результат верифицируется `og:title` страницы тайтла.
- Эвристика: Амедиатка почти весь каталог держит в подписке → «есть в каталоге» ≈ «по подписке».
- Проверено: «Поймать Мэри» ✅ (т Rwanda-совпадение 1-в-1), «Эйнштейн и Эддингтон» ✅
  (транслит `eynshteyn-i-eddington`), «лалаленд» → честное «не нашлось».

## Кион — отложено

Кион (kion.ru) — Angular-SPA с рендером на клиенте: страницы фильма не содержат статуса
в SSR, `kion-state` на полезных страницах пуст, API-шлюзы (`api.ma.kion.ru`,
`api-gateway.kls.mts-corp.ru/kls-api-gateway`, внутри START-стек) не отвечают на догадки
без ключей/заголовков устройства. Чтобы допилить: открыть страницу фильма с F12 → Network,
скопировать XHR к API (URL + нужен ли токен) — после этого парсер пишется за один заход.

## Smoke-тест

```bash
python3 test_smoke.py
```

Поднимает сервер как сабпроцесс, делает JSON-RPC handshake (`initialize` → `tools/list`)
и прогоняет вызовы всех инструментов, включая ground truth: «Трасса 60» должна быть
доступна на Кинопоиске, «Реквием по мечте» — нет. Требует сеть и uv, python-зависимостей
у самого теста нет.
